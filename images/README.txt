HEAVEN FURNITURE MART — IMAGE DROP-IN GUIDE
============================================

Download real photos from Heaven's own social media and save them into
THIS folder using the exact filenames below. The page detects them
automatically — no code changes needed. Until a file is present, an
elegant branded placeholder shows in its place.

WHERE TO GET THE PHOTOS
  Facebook  : facebook.com/HeavenFurnitureMart
  Instagram : instagram.com/heaven_furniture_ltd
  YouTube   : youtube.com/@HeavenFurnitureMart
  (Right-click a photo > Save image, or use the ... > Download on a post.)

FILENAMES TO USE (exact — lowercase, .jpg)
  hero.jpg        Big, wide, best-looking room / signature setting (landscape)
  studio.jpg      Showroom interior — used in "Who We Are" (portrait works best)
  living-room.jpg A sofa / living room set (portrait 3:4 looks best)
  bedroom.jpg     A bed / wardrobe setup (portrait 3:4)
  dining.jpg      Dining table set (portrait 3:4)
  office.jpg      Executive desk / office piece (portrait 3:4)
  bespoke.jpg     Your best custom / statement piece (portrait 4:5)
  cta.jpg         A warm, elegant interior — background behind final CTA (landscape)

TIPS
  - Use JPG. Aim for at least 1200px on the long edge, clean and sharp.
  - You may lightly touch up (crop, straighten, brighten, remove clutter).
    Keep it looking real — no distorted or obviously fake edits.
  - Prefer real Heaven photos over stock — they read as far more credible.
  - If you have a logo file, save it as logo.png (optional).

That's it. Add the files, refresh the page.
